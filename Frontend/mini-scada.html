Hardware Architecture

  • PV Array: 12 monocrystalline silicon panels configured in series/parallel.
  • Switching Matrix: High-speed solid-state relay array for dynamic string reconfiguration.
  • DAQ Unit: Hioki 8430-20 memory data logger with 10ms sampling rate.

Communication Protocols

  • Modbus RTU / TCP: Real-time inverter parameters & power telemetry.
  • IEC 60870-5-104: SCADA dispatching telecontrol standard compliant.
  • MQTT / WebSocket: Sub-second streaming to laboratory master control screen.
